# Raniel Escalante — Digital QA Portfolio

This is a static HTML/CSS/JavaScript portfolio. It uses no package manager, build system, backend, or API keys.

## Contents
- `index.html` — homepage including the featured Manila QA Tool and RFE Chrome Tools section.
- `assets/styles.css` — layout, color system, responsive design.
- `assets/main.js` — mobile navigation.
- `assets/favicon.svg` — website icon.
- `assets/Raniel_Escalante_Resume.pdf` — downloadable PDF resume (supplied by the portfolio owner).

## Outbound links
- RFE Chrome Tools: https://rfe-tools-website.onrender.com/index.html
- GitHub: https://github.com/ranielescalante
- Email: raniel.escalante@gmail.com

## Publish using the existing Render Static Site
Build Command: `mkdir -p dist && cp index.html dist/ && cp -R assets dist/`

Publish Directory: `dist`

See `DEPLOY-ON-RENDER.md` for browser-only upload steps.

## Editing
Update content in `index.html`, colors and layout in `assets/styles.css`, and the resume PDF inside `assets/`.

The QA panel in the hero is a **concept illustration**, not actual QA results. The RFE Chrome Tools panel is a visual illustration, not an authenticated screenshot of the external tools site. Check that any public details are appropriate to share before applying for jobs.
